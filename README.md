# 採算・価格分析

商品・顧客・案件別の採算、利益が動いた理由、値上げやプラン変更の比較の 3 つの Skill。

[CFO](https://github.com/p-take55/aachat-cfo) の Skill のうち、採算・価格分析にあたるものを Plugin にまとめたものです。単独で入れても使えます。

## 同梱の Skill

| Skill | すること |
|---|---|
| `cfo-profitability` | 商品・顧客・案件ごとの利益と損益分岐を出す |
| `cfo-margin-drivers` | 利益が増えた・減った理由を分解する |
| `cfo-pricing-options` | 値上げやプラン変更を採算で比べる |

## 使うときに

数字の元になる資料、扱う事業・期間・通貨、守りたい残高や使える予算を、要る範囲で渡してください。手元の資料からでも、使える接続からでも始められます。

- 実績・予定・仮定、利益と入出金、本人の工数を分けて扱い、分からない金額をゼロで埋めません。
- 外部サービスとつなぐ設定（MCP・認証）、定期実行、通知は同梱していません。
- 送金・注文・支払・借入・投資の取引・税の申告・契約の変更・外への送信はしません。この Plugin を入れたことを、それらの許可とは受け取りません。
